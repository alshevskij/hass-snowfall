# ❄️ Snowfall for Home Assistant

Добавьте атмосферу зимы на панели управления Home Assistant!✨

Snowfall - пользовательская интеграция, которая добавляет анимированный эффект падающего снега непосредственно в интерфейс Home Assistant. Управляйте снегопадом и всеми его параметрами через штатные сущности Home Assistant - без YAML и без отдельного окна параметров интеграции.

## Текущие возможности интеграции:

- Анимированный снег непосредственно в интерфейсе Home Assistant (абсолютно на любой странице).
- Переключатель для включения и выключения снегопада.
- Три встроенных режима работы: **Новогодний** (снег идёт только с декабря и по февраль), **Круглогодичный** и **Выбор месяцев**.
- 12 отдельных переключателей для каждого месяца в году. Они активны и используются только в режиме **Выбор месяцев**.
- Настройка количества, скорости, размера и прозрачности снежинок.
- Ограничение частоты отрисовки: 30 или 60 кадров в секунду.
- **Белый список** страниц, на которых разрешён снегопад.
- **Чёрный список** страниц, на которых снегопад запрещён.

## Установка интеграции:

### Через HACS (рекомендуется)

1. Убедитесь, что HACS установлен в Home Assistant.
2. Нажмите кнопку <p>
  <a href="https://my.home-assistant.io/redirect/hacs_repository/?owner=alshevskij&repository=hass-snowfall&category=integration">
    <img src="https://my.home-assistant.io/badges/hacs_repository.svg" alt="Добавить Snowfall в Home Assistant через HACS">
  </a>
</p>

3. Откройте репозиторий Snowfall в HACS и подтвердите добавление пользовательского репозитория.
4. Найдите Snowfall и установите интеграцию.
5. Перезагрузите Home Assistant.

Если кнопка не сработала, добавьте репозиторий вручную:

`https://github.com/alshevskij/hass-snowfall`

В HACS выберите категорию **Integration**.

### Ручная установка

1. Скачайте репозиторий.
2. Скопируйте папку `custom_components/snowfall` в каталог `custom_components` Home Assistant.
3. Перезагрузите Home Assistant.

## Настройка и сущности

После добавления интеграции откройте **Настройки → Устройства и службы → Snowfall → Устройство**. Здесь собраны переключатель снегопада и все параметры интеграции.

Основной переключатель сохраняет прежний ID `switch.snowfall`. Остальные сущности создаются автоматически:

| Сущность | Назначение |
|---|---|
| `switch.snowfall` | Включение и выключение снегопада |
| Переключатель режима | Новогодний, круглогодичный или выбор месяцев |
| 12 переключателей месяцев | Выбор активных месяцев; видны только в пользовательском режиме |
| Числовая настройка количества | Количество снежинок: 10–300 |
| Числовая настройка скорости | Скорость падения: 25–200 |
| Числовая настройка размера | Размер снежинок: 25–200 |
| Числовая настройка прозрачности | Прозрачность: 10–100 |
| Переключатель частоты кадров | 30 или 60 FPS |
| Текстовая сущность чёрного списка | Страницы, на которых снегопад запрещён |
| Текстовая сущность белого списка | Страницы, на которых снегопад разрешён |

Сущности используют названия на языке Home Assistant. Все они объединены в одно устройство **Snowfall** с моделью **Home Assistant FX**.

### Что изменилось

В этой версии управление снегопадом перенесено в полноценный набор сущностей Home Assistant:

- Вместо изменения параметров через прежнее окно настроек интеграции используются переключатели, селекторы, числовые и текстовые сущности прямо в устройстве Snowfall.
- Добавлены отдельные сущности для режима работы и частоты кадров.
- Добавлены числовые настройки количества, скорости, размера и прозрачности снежинок.
- Добавлены переключатели для каждого из 12 месяцев. Они автоматически скрываются в режимах **Новогодний** и **Круглогодичный**, а в режиме **Выбор месяцев** становятся доступны. Выбранные месяцы сохраняются при смене режима.
- Добавлен белый список страниц в дополнение к чёрному списку.
- Добавлено ограничение частоты отрисовки 30/60 FPS.
- Все сущности сгруппированы в одном устройстве, а модель устройства отображается как **Home Assistant FX**.
- Сохранённые ранее параметры из Options Flow переносятся в новые сущности при обновлении, поэтому существующие настройки не должны сбрасываться.

## Режимы работы

- **Новогодний** — снегопад разрешён с декабря по февраль.
- **Круглогодичный** — снегопад разрешён в любое время года.
- **Выбор месяцев** — снегопад разрешён только в те месяцы, переключатели которых включены.

Переключатели месяцев автоматически скрываются в режимах **Новогодний** и **Круглогодичный** и появляются при выборе **Выбор месяцев**. Сохранённые настройки месяцев при переключении режимов не сбрасываются.

## Белый и чёрный списки страниц

В текстовых сущностях указывайте пути страниц через точку с запятой или запятую. Например:

`/lovelace/home; /lovelace/lights; /config/dashboard`

Можно использовать и запятые:

`/lovelace/home, /lovelace/lights`

Указывайте путь, начинающийся с `/`, без домена, параметров запроса и фрагмента URL.

- **Белый список пуст** — снегопад разрешён на всех страницах, кроме перечисленных в чёрном списке.
- **Белый список заполнен** — снегопад разрешён только на совпадающих страницах.
- **Чёрный список** исключает указанные страницы из эффекта.
- Если путь совпадает с обоими списками, приоритет всегда у чёрного списка: снегопад на этой странице не отображается.
- Сопоставление учитывает вложенные страницы: правило `/lovelace` подходит также для `/lovelace/room`.

Каждая текстовая сущность Home Assistant ограничена 255 символами. Если список большой, используйте более короткие пути.

## Управление через автоматизации

Все сущности можно добавлять на панели, использовать в скриптах и автоматизациях. Например, можно включать `switch.snowfall` по расписанию, менять режим в зависимости от сезона или переключать параметры анимации.

Если вы хотите полностью управлять расписанием средствами Home Assistant, выберите режим **Круглогодичный**, а включение и выключение эффекта поручите автоматизациям.

Документация: [Автоматизации Home Assistant](https://www.home-assistant.io/docs/automation/).
