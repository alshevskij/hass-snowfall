# ❄️ Snowfall for Home Assistant

Добавьте атмосферу зимы на панели управления Home Assistant!✨

Snowfall - пользовательская интеграция, которая добавляет анимированный эффект падающего снега непосредственно в интерфейс Home Assistant. Управляйте снегопадом и всеми его параметрами через штатные сущности Home Assistant - без YAML и без отдельного окна параметров интеграции.

## Текущие возможности интеграции:

- Анимированный снег непосредственно в интерфейсе Home Assistant (абсолютно на любой странице).
- Переключатель для включения и выключения снегопада.
- Три встроенных режима работы: **Новогодний** (снег идёт только с декабря и по февраль), **Круглогодичный** и **Выбор месяцев**.
- 12 отдельных переключателей для каждого месяца в году с порядковой нумерацией от 1 до 12. Они активны и используются только в режиме **Выбор месяцев**.
- Настройка количества, скорости, размера и прозрачности снежинок, а также их внешнего вида.
- Четыре пресета снегопада: лёгкий, обычный, сильный и метель. Пресет меняет общую интенсивность, не перезаписывая ручные настройки.
- Четыре варианта внешнего вида: точки, шестилучевые снежинки, кристаллы и смешанный режим.
- Настраиваемый ветер: сила, направление и порывы; ветер влияет на горизонтальную траекторию каждой снежинки.
- Ограничение частоты отрисовки: 30, 60, 90 или 120 кадров в секунду.
- **Белый список** страниц, на которых разрешён снегопад.
- **Чёрный список** страниц, на которых снегопад запрещён.

## Установка интеграции:

### Через HACS / Marketplace (рекомендуется)

1. Убедитесь, что HACS установлен в Home Assistant.
2. Нажмите на кнопку ниже <p>
  <a href="https://my.home-assistant.io/redirect/hacs_repository/?owner=alshevskij&repository=hass-snowfall&category=integration">
    <img src="https://my.home-assistant.io/badges/hacs_repository.svg" alt="Добавить Snowfall в Home Assistant через HACS">
  </a>
</p>

3. Подтвердите добавление пользовательского репозитория.
4. Найдите Snowfall и установите интеграцию.
5. Перезагрузите Home Assistant.

Если кнопка не сработала, добавьте репозиторий вручную по ссылке:

`https://github.com/alshevskij/hass-snowfall`

В HACS выберите категорию **Integration**.

### Ручная установка

1. Скачайте репозиторий.
2. Скопируйте папку `custom_components/snowfall` в каталог `custom_components` вашего Home Assistant.
3. Перезагрузите Home Assistant.

## Устройства и профили настроек

Интеграция создаёт три логических устройства Home Assistant:

- **Snowfall** - глобальные настройки интеграции: включение и выключение эффекта, расписание снегопада, выбор режима настроек устройств, белый и чёрный списки страниц.
- **Snowfall Desktop** - визуальные параметры для компьютеров: количество, скорость, размер и прозрачность снежинок, внешний вид, пресет интенсивности, ветер и FPS.
- **Snowfall Mobile** - независимый набор тех же визуальных параметров для телефонов и планшетов.

Переключатель **Раздельные настройки устройств** в глобальных настройках интеграции управляет режимом работы профилей:

- **Выключен** - все браузеры используют профиль Snowfall Desktop. Элементы управления Snowfall Mobile автоматически скрываются (становятся неактивными), а сохранённые мобильные значения остаются нетронутыми.
- **Включён** - компьютеры используют Snowfall Desktop, а телефоны и планшеты - Snowfall Mobile. Тип клиента определяется непосредственно в браузере.

При обновлении интеграции с версии 2026.11.3 (или более старой) ваши прежние визуальные настройки переносятся в профиль Desktop. Существующие ID сущностей сохраняются, поэтому ранее созданные карточки и автоматизации не должны требовать перенастройки. Для Mobile создаётся отдельный профиль с начальными значениями по умолчанию.

Диагностические сенсоры профилей Desktop и Mobile доступны в стандартном списке сущностей и содержат атрибуты конфигурации, которые использует JavaScript-модуль интеграции.

## Настройка и сущности интеграции:

Основной переключатель снегопада, добавленный в версии 2026.10.1, сохраняет прежний ID `switch.snowfall`.
Начиная с версии 2026.11.3 штатные сущности для управления интеграцией создаются автоматически. В версии 2026.11.4 добавлены раздельные профили Desktop и Mobile, а также улучшено отображение диагностических сенсоров и переключателей месяцев.

| Сущность | Назначение |
|---|---|
| `switch.snowfall` | Включение и выключение снегопада |
| Переключатель режима | Новогодний, круглогодичный или выбор месяцев |
| 12 переключателей месяцев | Выбор активных месяцев (активны только в режиме выбора месяцев) |
| Числовая настройка количества | Количество снежинок: 10–300 |
| Числовая настройка скорости | Скорость падения: 25–200 |
| Числовая настройка размера | Размер снежинок: 25–200 |
| Числовая настройка прозрачности | Прозрачность: 10–100 |
| Выбор частоты кадров | 30, 60, 90 или 120 FPS |
| Выбор внешнего вида | Точки, шестилучевые снежинки, кристаллы или смешанный режим |
| Пресет снегопада | Лёгкий, обычный, сильный снегопад или метель |
| Сила ветра | 0–100 |
| Направление ветра | Влево, вправо или переменное |
| Порывы ветра | 0–100 |
| Текстовая сущность чёрного списка | Страницы, на которых снегопад запрещён |
| Текстовая сущность белого списка | Страницы, на которых снегопад разрешён |

### Что изменилось:

В версии 2026.11.4:
- Добавлены независимые профили визуальных настроек для Desktop и Mobile. При отключённом раздельном режиме все клиенты используют Desktop-профиль; при включённом компьютеры используют Desktop, а телефоны и планшеты - Mobile.
- Существующие визуальные настройки автоматически переносятся в Desktop-профиль при обновлении. Значения Mobile сохраняются при отключении раздельного режима.
- Диагностические сенсоры профилей Desktop и Mobile отображаются в стандартном списке сущностей и предоставляют параметры профилей фронтенду.
- Переключатели месяцев переименованы с их порядковыми номерами в календаре для более логичного визуального отображения: 1. Январь - 12. Декабрь.

## Белый и чёрный списки страниц:

В текстовых сущностях указывайте пути страниц через точку с запятой или запятую. Например:

`/lovelace/home; /lovelace/lights; /config/dashboard`

Можно использовать и запятые:

`/lovelace/home, /lovelace/lights`

Указывайте путь, начинающийся с `/`, без домена, параметров запроса и фрагмента URL.

- **Белый список пуст** - снегопад разрешён на всех страницах, кроме перечисленных в чёрном списке.
- **Белый список заполнен** - снегопад разрешён только на совпадающих страницах.
- **Чёрный список** исключает указанные страницы из эффекта.
- Если путь совпадает с обоими списками, приоритет всегда у чёрного списка: снегопад на этой странице не отображается.
- Сопоставление учитывает вложенные страницы: правило `/lovelace` подходит также для `/lovelace/room`.

Каждая текстовая сущность Home Assistant ограничена 255 символами. Если список большой, используйте более короткие пути.

Все сущности интеграции, разумеется, можно добавлять на ваши панели и организовывать с их помощью удобные карточки для управления параметрами, например:

А также использовать в автоматизациях, например, можно включать `switch.snowfall` по расписанию, менять режим в зависимости от сезона или переключать параметры анимации, и если вы хотите полностью управлять расписанием снегопада средствами Home Assistant, выберите режим **Круглогодичный**, а включение и выключение эффекта поручите автоматизациям.
